# Банк заданий

Файлы по группам классов: `1-2.json`, `3-4.json`, `5-6.json`, `7-8.json`, `9-11.json`.
Внутри разделы: `math`, `rus`, `nature`, `logic`, `quiz`.
Отдельно `common.json`: `razbor` (разборы недели) и `family` (семейные задания).

Формат задания:

```json
{"q": "текст задания", "a": "ответ и короткое пояснение"}
```

Пополнять просто: добавить элемент в нужный список. Ничего перезапускать не нужно,
сборщик подхватит его со следующего запуска.

Правила для заданий:
- одно задание в 1–3 предложения, чтобы помещалось в пост;
- ответ всегда с пояснением, а не только число;
- никакого текста из учебников дословно, формулировки свои;
- для `math` банк можно не пополнять: примеры генерируются автоматически в `scripts/bank.py`.

Повторы отслеживаются в `state/used.json`. Когда раздел заканчивается, круг начинается заново.
