# Банк заданий

Файлы по группам классов: `1-2.json`, `3-4.json`, `5-6.json`, `7-8.json`, `9-11.json`.
Внутри разделы: `math`, `rus`, `nature`, `logic`, `quiz`.
Отдельно `common.json`: `razbor` (разборы недели) и `family` (семейные задания).

Формат задания:

```json
{"q": "текст задания", "a": "ответ и короткое пояснение"}
```

Как сборщик берёт задания:
- по порядку, первое ещё не выходившее, поэтому списки выстроены по ходу школьного года
  (ноябрь, декабрь, январь, февраль). Новые задания добавляйте в конец списка;
- `math`: сначала текстовые задачи из банка по порядку, когда они кончатся, примеры из генератора
  `scripts/bank.py`. В субботних «Задачах на выходные» всегда примеры из генератора;
- в `family` ответ пишется в конце текста после слов «Ответ:», сборщик прячет его под спойлер.

Запас на 24 сентября 2026 года: по 26 заданий в `rus`, `nature`, `logic`, `quiz` и 20 задач в `math`
для каждой группы, 20 разборов и 20 семейных заданий. Утренние посты собраны заранее до 31 декабря 2026 года.
После этого заданий по предметам хватит примерно до конца марта 2027 года, разборов и семейных заданий
до февраля. Когда список кончается, круг начинается заново.

Правила для заданий:
- одно задание в 1–3 предложения, чтобы помещалось в пост;
- ответ всегда с пояснением, а не только число; без точки в конце, со строчной буквы;
- никакого текста из учебников дословно, формулировки свои.

Повторы отслеживаются в `state/used.json`.

Собрать посты заранее на даты в будущем:

```
python scripts/build_posts.py --today 2027-01-01 --days 31
```
