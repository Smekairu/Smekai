# Сайт Смекай

Статический сайт, работает на GitHub Pages без сервера и без сборки.

## Что где

| Файл | Что это |
|---|---|
| `index.html` | главная: обещание, как работает, где заниматься, отличие, Мыслик и Лев, тарифы, вопросы |
| `kak-rabotaet.html`, `tarify.html`, `faq.html`, `lev.html`, `rekvizity.html` | отдельные страницы для ссылок из меню и подвала |
| `zanyatie/index.html` | занятие в браузере для планшета и компьютера: задания с подсказками, три в день бесплатно |
| `assets/site.css`, `assets/site.js` | общие стили и сценарии: шапка, подвал, всплывающие окна, плашка cookie, плавающий Мыслик |
| `assets/pack/` | стикеры 512, эмодзи 100, наборы для соцсетей 256 и 128, оба персонажа |
| `viktorina/index.html` | викторина, раньше лежала в корне |
| `oferta.html` | публичная оферта |
| `policy.html` | политика обработки персональных данных |
| `404.html` | страница, если адрес не найден |
| `myslik/index.html` | страница персонажа: настроения, облачко, выбор голоса |
| `assets/myslik.js` | анимированный Мыслик, один файл, подключается на любую страницу |
| `assets/anim/` | стикеры и анимации Мыслика для Telegram и MAX |
| `assets/fonts/`, `assets/fonts.css` | шрифты Unbounded и Golos, лежат у нас, внешних запросов нет |
| `assets/` | логотипы и иконка |
| `robots.txt`, `sitemap.xml` | для поисковиков |

## Как выложить

Файлы кладутся в корень репозитория Smekairu/Smekai, поверх нынешних.
Важно: старый `index.html` с викториной переезжает в папку `viktorina`, поэтому
ссылка на викторину меняется с `smekairu.github.io/Smekai/` на
`smekairu.github.io/Smekai/viktorina/`.

Через сайт GitHub: Add file → Upload files → перетащить содержимое папки → Commit.

После этого поправить ссылку на викторину в двух местах:
`scripts/publish.py`, значение `LINKS["quiz"]`, и описание канала в Telegram.

## Перед публикацией заменить

1. ИНН и ОГРНИП в подвале главной, в оферте и в политике: сейчас там нули.
2. Почту `hello@smekai.ru` на рабочую. Пока домена нет, можно поставить бот.
3. Проверить, что бот `@smekai_ru_bot` отвечает: на него ведут все кнопки.

## Счётчик посещений

Счётчик подключается одним числом: в каждой странице у тега `<body>` есть атрибут `data-metrika=""`.
Заведите счётчик на metrika.yandex.ru и впишите его номер в кавычки. Счётчик загружается только после
того, как посетитель нажал «Хорошо» на плашке cookie, как требует закон о персональных данных.

## Всплывающие окна и плавающий помощник

Кнопки «Начать», «Подключить», «Канал с заданиями» и «Поддержка» открывают окна, а не уводят с сайта.
Ссылки на соцсети только по иконкам в подвале. Плавающий Мыслик появляется на всех страницах, кроме
документов и занятия; его можно перетащить, положение запоминается. Отключить на странице: `data-float="off"` у `<body>`.

## Свой домен

Когда купите smekai.ru: в настройках репозитория Pages указать домен,
у регистратора прописать CNAME на smekairu.github.io. Сертификат GitHub выпустит сам.
В `sitemap.xml`, `robots.txt` и `404.html` заменить адреса на новый домен.
