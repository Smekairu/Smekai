# Оплата: что работает сейчас и как подключить приём на сайте

## Сейчас

Страница `oplata.html` и вкладка «Тариф и оплата» в личном кабинете принимают оплату только на
`myslik.ru` через ЮKassa. Переадресации на Boosty в сценарии оплаты нет. Пока магазин ЮKassa не
активирован, посетитель видит сообщение о временной недоступности оплаты и контакты поддержки.

Для проверки магазина предусмотрен отдельный временный вход покупателя по логину и паролю.
На сервере хранится только хеш временного пароля; вход можно отключить после модерации.

## ЮKassa: автоматическая оплата на сайте

Когда запущен сервер кабинета (docs/server.md, раздел 5), оплата идёт прямо на сайте, а доступ открывается сам.

1. Подключить магазин на yookassa.ru как ИП, пройти проверку, подписать договор.
2. Подключить «Чеки от ЮKassa», чтобы чеки по 54-ФЗ выдавались автоматически.
3. В разделе «Интеграция → Ключи API» получить shopId и секретный ключ.
4. В GitHub → Settings → Secrets and variables → Actions добавить секреты
   `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET`, затем запустить workflow
   «Подключить ботов к серверу». Сервер получит настройки без показа ключа в логах.
   Если подключены «Чеки от ЮKassa», добавить переменную Actions
   `YOOKASSA_RECEIPT=1`.
   Для локального запуска те же значения можно положить в `bot/.env`:
   ```
   YOOKASSA_SHOP_ID=...
   YOOKASSA_SECRET=...
   YOOKASSA_RECEIPT=1
   ```
5. В «Интеграция → HTTP-уведомления» указать `https://myslik.ru/pay/yookassa` и событие `payment.succeeded`.
6. Перезапустить `myslik-pay`, провести тестовый платёж в тестовом магазине ЮKassa.

После этого на странице оплаты два способа: «Картой или МИР» (страница ЮKassa) и «СБП по QR-коду»
(код рисуется на сайте, страница сама видит, что оплата прошла). Автосписаний нет: каждый платёж за выбранный срок.
Тариф «Семья» открывает доступ плательщику и двум привязанным к нему детям.

Альтернативы ЮKassa с похожей схемой: Т-Банк Касса, Робокасса, CloudPayments. Для них нужен свой модуль
вместо `bot/pay_yookassa.py`, остальное не меняется.
