# Боты Смекай в Telegram и MAX: настройка и запуск

Оба бота работают из одной папки `bot/` и говорят одними словами. Telegram: `main.py`, MAX: `max_bot.py`.
Задания по математике 1–11 класса, подсказки, разбор, стикеры по возрасту (младший Мыслик, Мыслик, Лев),
голос, код родителя, отчёт по воскресеньям, тарифы, личный кабинет и поддержка.

## Что уже сделано автоматически

Workflow «Настроить ботов» (GitHub → Actions → Настроить ботов → Run workflow) ставит обоим ботам:
имя «Мыслик · Смекай», описание, список команд, а боту в MAX ещё и аватар. Токены берёт из секретов
`TG_BOT_TOKEN` и `MAX_BOT_TOKEN`, которые уже есть. Запускать можно сколько угодно раз.

Команды у обоих ботов одинаковые:

| Команда | Что делает |
|---|---|
| /start | знакомство или возврат в меню; `/start site` запомнит, откуда пришёл человек |
| /task | новое задание |
| /kabinet | ссылка в личный кабинет на сайте |
| /progress | сколько решено сегодня, всего, без подсказок, дней подряд |
| /pay | тарифы и оплата |
| /voice | выбрать голос |
| /parent | код для родителя или список детей |
| /report | отчёт о ребёнке прямо сейчас |
| /support | помощь: оплата, возврат, вопросы |
| /help | как это работает |
| /grant id дней тариф | только администратор: открыть тариф вручную (tasks, myslik, family) |
| /reply номер текст | только администратор: ответить на обращение в поддержку |
| /id | только MAX: показать свой user_id |

## Бесплатно в MAX

В MAX задания для детей бесплатны: бот даёт до 30 заданий в день всем, без тарифа, а утренние задания
из закрытого канала Telegram публикуются в открытом канале MAX (ответы через час).
Управляется двумя переменными, по умолчанию включено: `MAX_FREE_TASKS=1` (бот) и `MAX_TASKS_FREE=1` (публикатор).
Разбор домашки по фото и отчёт родителю остаются в тарифе.

## Поддержка

Мыслик сам отвечает на частые вопросы: как оплатить, сколько стоит, как вернуть деньги, как отменить,
«оплатил, а доступа нет», кабинет, отчёты, MAX. Любое сообщение, которое не похоже на ответ к заданию,
бот воспринимает как вопрос в поддержку. Кнопки «Оформить возврат» и «Написать человеку» принимают
заявку одним сообщением и присылают её администратору с номером. Ответ: `/reply номер текст`.
Тексты ответов в `assets/support.json`, их же использует сайт.

## Что делается руками, по одному разу

### Telegram, в @BotFather

1. `/setuserpic` → выбрать бота → отправить файл `assets/avatar-myslik.png`.
2. `/setjoingroups` → Disable: бот только для личных чатов.
3. Свой telegram id узнать у @userinfobot и вписать в `.env` как `ADMIN_ID`.

### MAX

1. Аватар, имя, описание и команды ставит скрипт; проверить, что видны.
2. Свой user_id в MAX: написать боту `/id` после запуска, вписать в `.env` как `MAX_ADMIN_ID`.
3. Если нужен отдельный платный канал в MAX, создать его, добавить бота и положить ссылку-приглашение
   в `MAX_CHANNEL_INVITE`. Сейчас задания в MAX бесплатны, поэтому это не обязательно.

## Файл .env

Скопировать `bot/.env.example` в `bot/.env` и заполнить. Обязательные строки:

```
TG_BOT_TOKEN=          токен от BotFather
ADMIN_ID=              ваш telegram id
MAX_BOT_TOKEN=         токен от MasterBot
MAX_ADMIN_ID=          ваш user_id в MAX
```

Остальное можно оставить как есть. Без ключей Яндекса бот отвечает текстом и не разбирает фото,
всё остальное работает. База одна на оба бота: `myslik.db`.

## Запуск

### Вариант 1. На своём компьютере, пока нет сервера

Нужен Python 3.11 или новее с python.org (при установке отметить «Add python.exe to PATH»).

1. Папка `bot` из репозитория, рядом с ней должна лежать папка `assets` (стикеры и тексты поддержки).
   Проще всего взять папку `07 Сайт` целиком.
2. Заполнить `bot/.env`.
3. Дважды щёлкнуть `bot/start-windows.bat`. В окне появятся строки «Мыслик запущен» и «Мыслик в MAX запущен».
4. Написать боту `/start` в Telegram и в MAX.

Боты работают, пока открыто это окно и включён компьютер. Личный кабинет в этом режиме хранит прогресс
на устройстве ребёнка; общий прогресс с ботом включится вместе с сервером.

### Вариант 2. Сервер (постоянная работа)

Установка в `docs/server.md`: три сервиса `myslik`, `myslik-max`, `myslik-pay`, отчёт в cron,
а для кабинета и оплаты на сайте ещё nginx с HTTPS (раздел 5).

## Проверка

1. В Telegram: `/start`, имя, класс, голос, «Задание», ответить неверно, взять подсказку, ответить верно.
2. В MAX то же самое: меню кнопками под сообщением, стикеры картинками, заданий 30 в день бесплатно.
3. Класс 9–11: отвечает Лев.
4. «🏠 Кабинет»: ссылка открывает личный кабинет с именем и классом.
5. «🛟 Помощь» → «Вернуть деньги» → «Оформить возврат»: заявка приходит администратору, `/reply 1 текст` доходит.
6. Родитель: с другого аккаунта прислать код из «Родителю», затем `/report`. Работает и между Telegram и MAX.

## Если что-то не так

- Бот молчит: посмотреть окно запуска или `journalctl -u myslik -n 50`. Чаще всего неверный токен или нет интернета.
- MAX пишет про сертификат: поставить сертификаты Минцифры (`docs/server.md`, раздел 1).
- Стикеры не приходят: рядом с `bot` нет папки `assets`. Бот при этом работает текстом.
- В MAX кнопки не нажимаются: обновить приложение MAX.
- Голос не приходит: нет `YANDEX_API_KEY` и `YANDEX_FOLDER`, это ожидаемо до появления ключа.
