# Боты Смекай в Telegram и MAX: настройка и запуск

Оба бота работают из одной папки `bot/` и говорят одними словами. Telegram: `main.py`, MAX: `max_bot.py`.
Задания по математике 1–11 класса, подсказки, разбор, стикеры по возрасту (младший Мыслик, Мыслик, Лев),
голос, код родителя, отчёт по воскресеньям, подписка.

## Что уже сделано автоматически

Workflow «Настроить ботов» (GitHub → Actions → Настроить ботов → Run workflow) ставит обоим ботам:
имя «Мыслик · Смекай», описание, список команд, а боту в MAX ещё и аватар. Токены берёт из секретов
`TG_BOT_TOKEN` и `MAX_BOT_TOKEN`, которые уже есть. Запускать можно сколько угодно раз.

Команды у обоих ботов одинаковые:

| Команда | Что делает |
|---|---|
| /start | знакомство или возврат в меню; `/start site` запомнит, откуда пришёл человек |
| /task | новое задание |
| /progress | сколько решено сегодня, всего, без подсказок, дней подряд |
| /voice | выбрать голос |
| /parent | код для родителя или список детей |
| /report | отчёт о ребёнке прямо сейчас |
| /help | как это работает |
| /grant id дней | только администратор: включить подписку вручную |
| /id | только MAX: показать свой user_id |

## Что делается руками, по одному разу

### Telegram, в @BotFather

1. `/setuserpic` → выбрать бота → отправить файл `assets/avatar-myslik.png` (лежит в 07 Сайт/assets и на сайте).
2. `/setjoingroups` → Disable: бот только для личных чатов.
3. `/setinline` пропустить, инлайн-режим не нужен.
4. Свой telegram id узнать у @userinfobot и вписать в `.env` как `ADMIN_ID`.

### MAX, в @MasterBot

1. Открыть бота → Настройки. Аватар, имя, описание и команды уже записаны скриптом; проверить, что видны.
2. Свой user_id в MAX: написать боту `/id` после запуска, вписать в `.env` как `MAX_ADMIN_ID`.
3. Закрытый канал в MAX: создать канал, добавить бота, в настройках канала взять ссылку-приглашение
   и положить в `.env` как `MAX_CHANNEL_INVITE`. Эту ссылку бот присылает после `/grant`.
   Автоматической выдачи по оплате в MAX пока нет: Tribute присылает только telegram id.

## Файл .env

Скопировать `bot/.env.example` в `bot/.env` и заполнить. Обязательные строки:

```
TG_BOT_TOKEN=          токен от BotFather
ADMIN_ID=              ваш telegram id
MAX_BOT_TOKEN=         токен от MasterBot
MAX_ADMIN_ID=          ваш user_id в MAX
PAY_URL=https://boosty.to/smekai
TG_CHANNEL_CLOSED=-1004434463581
```

Остальное можно оставить как есть. Без ключей Яндекса бот отвечает текстом и не разбирает фото,
всё остальное работает. Базы у ботов раздельные: `myslik.db` и `myslik-max.db`.

## Запуск

### Вариант 1. На своём компьютере, пока нет сервера

Нужен Python 3.11 или новее с python.org (при установке отметить «Add python.exe to PATH»).

1. Папка `bot` из репозитория, рядом с ней должна лежать папка `assets` (стикеры и картинки).
   Проще всего клонировать весь репозиторий или взять папку `07 Сайт` целиком.
2. Заполнить `bot/.env`.
3. Дважды щёлкнуть `bot/start-windows.bat`. Откроется окно, в нём строки «Мыслик запущен» и «Мыслик в MAX запущен».
4. Написать боту `/start` в Telegram и в MAX.

Боты работают, пока открыто это окно и включён компьютер. Закрыть окно = остановить ботов.

### Вариант 2. Сервер (постоянная работа)

Установка описана в `docs/server.md`. Для MAX добавляется третий сервис `myslik-max.service`,
он там же, и строка в cron для отчётов в MAX. Кратко:

```bash
cd /root/Smekai && git pull
cd bot && . .venv/bin/activate && pip install -r requirements.txt
sudo systemctl enable --now myslik myslik-max myslik-pay
sudo journalctl -u myslik-max -f
```

## Проверка

1. В Telegram: `/start`, имя, класс, голос, «Задание», ответить неверно, взять подсказку, ответить верно.
   Должны прийти стикеры: приветствие, «думает», «ура».
2. В MAX то же самое, только меню приходит кнопками под сообщением, а стикеры картинками.
3. Класс 9–11: вместо Мыслика отвечает Лев (другие стикеры, голос «Лев»).
4. Родитель: с другого аккаунта прислать код из «Родителю», затем `/report`.
5. `/grant свой_id 30`: в Telegram придёт одноразовая ссылка в закрытый канал, в MAX ссылка из `MAX_CHANNEL_INVITE`.

## Если что-то не так

- Бот молчит: посмотреть окно запуска или `journalctl -u myslik -n 50`. Чаще всего неверный токен или нет интернета.
- MAX пишет про сертификат: на сервере поставить сертификаты Минцифры (`docs/server.md`, раздел 1).
- Стикеры не приходят: рядом с `bot` нет папки `assets`. Бот при этом продолжает работать текстом.
- В MAX кнопки не нажимаются: обновить приложение MAX, старые версии не показывают inline-кнопки.
- Голос не приходит: нет `YANDEX_API_KEY` и `YANDEX_FOLDER`, это ожидаемо до появления ключа.
